Architecture & Stack

📱 Framework

Flutter (Dart SDK ≥ 3.3.0). Targets Android & iOS. Locked to portrait orientation. Feature-based folder structure under lib/features/.

⚙️ State Management

Riverpod v2 with riverpod_annotation code generation. StateNotifierProvider for GuardianState; @riverpod codegen for auth & onboarding notifiers.

🗺️ Routing

go_router v14 with async redirect guards: first-launch → onboarding, then → auth, then → home. No deep-links yet.

🎨 Design System

Dark glassmorphism theme. Custom GlassCard & NeonButton components. Font: Plus Jakarta Sans (5 weights). Animated via flutter_animate.

Audio Classifier (TFLite)

🎯 Model Specs

16 kHz mono PCM input. 1-second window = 15,600 samples. Output classes: Background, Scream, Help, Crying. Distress threshold: probability > 65%.

🔄 Fallback Mode

If no .tflite file is present in assets/ml/, falls back to an RMS amplitude heuristic (RMS > 0.15 = distress). Pipeline stays functional during development.
